# Changelog

## 1.2.0 (2026-11-05)

The Owner's 28 page rules are now recorded in the ontology. Each rule has the Owner instruction it comes from, one of eleven page qualities (new: predictable, working behaviour, specific answers, navigable, readable, adaptable, economy of space, clear structure, comprehensible, engaging, focused content) and one of the ten kinds of page part. New classes: page rule, Owner instruction, page quality. New shape: every page rule has exactly one source, quality and kind of part. T-Box v1.2.0, A-Box v1.2.0, shapes v1.2.0 (the earlier files are retired).
