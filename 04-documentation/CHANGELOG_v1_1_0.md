# Changelog

## 1.1.0 (2026-11-04)

Quality standards tied to page parts. New class "quality standard or method"; the link "applies to" now also leads from a standard to the page parts it governs. The A-Box records ten standards and methods (WCAG 2.2 AA, Nielsen's heuristics, Shneiderman's rules, cognitive load theory, axe-core, pa11y, WAVE, WAI-ARIA, Inclusive Components, ISO/IEC 25010), each with a source and at least one page part. One new shape asks that every standard applies to some page part. T-Box and A-Box are v1.1.0 (earlier versions retired).
