# IPage 1.5.0

Date: 2026-11-05. The default page format is built from the ontology, and it passes every gate.

- `01-ontologies/interactive_page_ontology_tbox_v1_3_0.ttl` -> `v1_4_0.ttl` (old version archived, not deleted, as this directory's established practice): adds `ipo:DefaultPageFormat` (a subclass of `ipo:Page`) and `ipo:builtFrom` (domain `ipo:DefaultPageFormat`, range `owl:Ontology`), so a default page format can name the ontology it was built from.
- `01-ontologies/interactive_page_ontology_abox_v1_2_0.ttl` -> `v1_3_0.ttl` (old version archived): adds `ipo:DefaultFormat_01`, the one default page format individual, `ipo:builtFrom` the T-Box's own ontology IRI.
- `06-page-measure/measure_page_rules_v1_0_0.py` -> `v1_1_0.py`: objective A7b's metric (`measure_page_ontology_v2_1_0.py`'s `m_default_pages_passing()`) invokes this instrument with the page path as a bare positional argument and reads its exit code as the page's pass/fail verdict -- v1.0.0 only recognised `--page` and always exited 0 regardless of outcome, so that metric could never genuinely read 1. Fixed: a bare positional path is now accepted alongside `--page`, and the process exits 0 only if every one of the 56 (rule, viewport) checks passed, 1 otherwise. No rule's check function changed; `--selftest` still passes.
- `08-default-format/default_page_format_v1_0_0.html`: the one default page format. Every new course page starts from this file unless its own profile names a different one. Built in the navy-and-gold visual language already shared by the RDODI, CME and VAF interactive pages (a dark top bar, a gold-accented tab underline, a light explorer and content area), it carries every page-part convention the 28 page rules check for, and `measure_page_rules_v1_1_0.py` reads it as passing all 56 checks (28 rules x 2 viewports) with exit code 0.
- Objectives read: A7a (default page formats) = 1, A7b (default-format pages passing every gate) = 1, the mission objective (default formats built from the ontology, traced) = 1.
