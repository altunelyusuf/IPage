What this page is

This is the default page format of the interactive page ontology: every course page that does not name its own profile starts from this file, inherits its markup conventions, and is measured against the same 28 page rules before it is published.

Why a single default format ↓
One default means one set of rule checks to keep green; a page that needs something different names its own profile instead of silently drifting from this one.

Detail

The interactive page ontology is the set of classes and rules that every interactive course page in this ecosystem is checked against. It names 28 page rules, a default page format built from itself, and the browser measurement that checks a page against each rule at two screen widths.
