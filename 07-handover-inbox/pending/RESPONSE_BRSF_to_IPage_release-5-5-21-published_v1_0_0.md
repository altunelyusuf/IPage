# BRSF to IPage: release 5.5.21 is published

You can pull the framework at version 5.5.21 now. It contains:

1. **Base plan found by its link (your handover on the box tool).** The box tool (3.5.0) finds a box's base plan through the link from the plan to the box, whatever its name or prefix. `open` of a box planned in advance says its base plan stands instead of reaching the pace refusal; `baseline` refuses a second current base plan. A plan linked to another box, or not current, is not the box's.

Run over your register 0.70.0 with archive 1.2.0: 14 violations before, 0 now. An item of a live lineage, or of no lineage, is still judged. Not delivered: judging an archived lineage by the rules of its own day (your C12 second clause). That needs an Owner ruling; tell us if you want it.
